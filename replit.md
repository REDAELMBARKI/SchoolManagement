# School Management System

## Project overview

This repository contains a School Management System with:

- `frontend/`: React, TypeScript, Vite, Tailwind CSS, and React Hook Form.
- `Backend/`: ASP.NET Core / .NET API using Clean Architecture and domain services.

The primary Replit preview runs the frontend with:

```bash
cd frontend
npm run dev
```

The student registration experience is available at `/list/students/new` and is currently preview-only: it validates the form and logs the backend-shaped payload instead of posting to the API.

## User preferences

- Keep the existing React/Vite and .NET project structure; do not migrate stacks.
- Use the existing SchooLama component language, soft sky/lilac/yellow accents, and warm sand/paper textures for new screens.
- Prefer realistic local seed data for UI-only foreign-key selects until backend query endpoints are connected.
