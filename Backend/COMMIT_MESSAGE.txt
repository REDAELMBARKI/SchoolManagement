fix: Complete slug generation and RequestDto pattern for Teacher and Opc entities

## Summary
Fixed missing slug generation for Teacher and Opc Person entities and completed
RefundRequestDto implementation to finalize the RequestDto → Command pattern
across the entire API.

## Changes

### Teacher Entity Slug Generation
- Convert TeacherCommand from record/init to class/set for mutability
- Convert UpdateTeacherCommand from record/init to class/set, add Slug property
- Add ExistsBySlugAsync() to ITeacherRepository interface
- Implement ExistsBySlugAsync() in TeacherRepository
- Add slug generation in TeacherService.CreateAsync (FirstName-LastName-Phone)
- Add slug regeneration in TeacherService.UpdateAsync (if name/phone changed)

### Opc Entity Slug Generation
- Add ExistsBySlugAsync() to IOpcRepository interface
- Implement ExistsBySlugAsync() in OpcRepository
- Add slug generation in OpcService.CreateAsync (FirstName-LastName-Phone)
- Add slug regeneration in OpcService.UpdateAsync (if name/phone changed)

### Refund RequestDto Pattern
- Create RefundRequestDto with Amount and Reason properties
- Create RefundMapper with ToDomain and ToResponse methods
- Update RefundService to use RefundMapper instead of direct entity creation
- Update PaymentController to use RefundRequestDto → RefundCommand
- Update RefundController to use RefundRequestDto → RefundCommand
