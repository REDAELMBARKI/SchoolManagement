## Architecture Improvements

### Slug Generation (SEO-Friendly URLs)
All public-facing entities now have unique, SEO-friendly slugs:
- Person entities: Teacher, Opc, Student, Intake, CommercialAgent, StudentResponsable
- Resource entities: Branch, Gender, Subject, Platform, Ad, Group
- Pattern: CustomSluger.Slug(existsDelegate, baseSlug) with automatic GUID suffix on conflicts
- Regeneration: Slugs update automatically when source fields change

### RequestDto → Command Pattern
Complete separation of concerns:
- RequestDto: User input only, with validation attributes
- Command: Enriched with context (branchId, userId, slug, timestamps)
- Service: Business logic and persistence
- Controller: Thin orchestration layer

### Mapper Standardization
All services now use dedicated mappers:
- Eliminates direct entity creation in services
- Centralizes mapping logic
- Consistent pattern: Mapper.ToDomain(command) and Mapper.ToResponse(entity)
